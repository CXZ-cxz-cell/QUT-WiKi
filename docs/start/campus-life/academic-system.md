# 教务系统
>教务系统可谓是每位同学在校期间最常用的系统之一，尽早摸清教务系统的功能和使用方法，能让你在选课、查课表、查成绩等方面事半功倍。

- 登入[教务系统](http://jxgl.qut.edu.cn/jwglxt/xtgl/login_slogin.html)，选择统一身份认证登入

## 自主选课
>青岛理工大学的选课系统为自主选课模式，学生可在规定时间内自主选择课程。
>
>一门课程可能会有多位老师开课，同学们可以根据自己的时间安排和老师的授课风格选择适合自己的课程。


- 每次选课之前，学委和导师都会发布**选课课表**，里面标注了**课程号，课程名，选必修**等等信息，同学们可以根据课表信息进行选课，避免选错课程。
- 进入系统后，上方菜单栏选择**选课**>>>**自主选课**。
- 选课界面会有很多筛选信息，包括**开课学院，年级，学生所在学院，课程类型**等，选择好后点击**查询**即可看到符合条件的课程列表。
- 选课时，点击课程列表中的**选课**按钮即可选课成功，若课程已满员，则会提示选课失败。
- 系统内会有学分统计，注意核对总学分是否和**选课课表**的学分一致。

## 课表查询

- 进入系统后，上方菜单栏选择**信息查询**>>>**个人课表查询**。
- **个人课表查询**界面会显示你所选课程的上课时间、上课地点、授课老师等信息，方便同学们安排自己的学习和生活。
- 同学们可以选择学年和学期，查询不同学期的课表信息。也可导出为PDF文件，方便打印和保存。

## 考试&成绩查询

- 进入系统后，上方菜单栏选择**信息查询**>>>**考试信息查询**/**学生成绩查询**。
- 
- 成绩查询其中**不合格**的用**红色标识**，通过**补考或重修及格**的用**蓝色标识**
