# 水电费充值
>水费用于饮用水和淋浴用水消费
>
>电费用于照明电(宿舍内除空调以外的所有用电器)和空调电消费

## 充值方式


### 小程序充值

- 打开支付宝，搜索“**完美校园**”小程序,点击下方**缴费**
- 选择校区，宿舍楼栋和房间号，进行充值
- 水费和电费充值后均可即时到账

### 一卡通充值

- 打开支付宝，搜索“**完美校园**”小程序，最上方进行充值
- 不同于小程序直充，一卡通充值完成后，水费可即时到账；但电费需要先去食堂充值机进行刷新，再去宿舍楼下的充值机进行充值
