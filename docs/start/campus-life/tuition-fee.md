# 缴费系统

## 学费组成说明

- 学费分为**基础学费和学分学费**，学分学费是根据学生所选课程的学分数计算的费用。
- 所以，不同专业甚至不同同学每个学期的学费总额可能会有所不同。但是四年平均学费是符合学校文件的。
- 其中**1学分 = 100人民币**，如果重修则需重交学分学费。


## 学宿费缴费方式

- 进入[学校OA系统](https://portal.qut.edu.cn/)，点击“缴费平台（学宿费）”进入缴费页面
- 点击菜单栏**学宿费缴费**，一路点击下一步即可

## 校园网缴费方式

- 进入企业微信，点击**学生服务**，选择**校园网缴费**，进入缴费页面
- 选择套餐类型，点击续费缴费即可
- 注意每晚23:00-24:00为后台对账时间，不支持缴费
- 套餐费用如下表所示

| **下载速率**         | **最多设备数** | **费用** |
|------------------|-----------|--------|
| 20Mbps=1.25MB/s  | 2         | 10/月   |
| 100Mbps=12.5MB/s | 4         | 30/月   |
| 60Mbps=7.5MB/s   | 3         | 100/学期 |
| 60Mbps=7.5MB/s   | 3         | 180/年  |
| 100Mbps=12.5MB/s | 4         | 240/年  |
