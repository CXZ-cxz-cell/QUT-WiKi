# 交通出行

> 本篇将介绍学校内外的交通方式，帮助你更好地在校园内和校外出行。

## 交通卡

- 在国家“交通联合”政策推广下，全国已经有超过300个城市的公交、地铁等交通工具可以使用同一张交通卡。
- “琴岛通”是青岛市发行的交通卡，对青岛市的公交，地铁有优惠政策，同学们可以通过下载“青岛地铁”APP；手机开启NFC，绑定“琴岛通”交通卡；或者进入微信，支付宝交通卡小程序等等。
- 文末我会附上“交通联合”城市列表，方便同学们查询。



## 黄岛校区

### 校内交通

| 交通工具             | 费用   | 备注                                  |
|------------------|------|-------------------------------------|
| 步行、私有自行车        | /    | 黄岛校区由于地形没有共享自行车                     |
| 私有电动车            | /    | 自2025级起，学校不再登记新的私有电动车进校园            |
| 共享电动车(小程序沃易行)    | 起步1元 | 1km&20min以下收费1元，暂时停车最多30min         |
| 摆渡车(小程序享坐车)      | 2元/人 | 从校内多个站点和南2门之间往返                     |
| 地铁站摆渡公交(小程序e定真情) | 2元/人 | 从校内多个站点和薛家岛地铁站之间往返，出校允许交通卡二维码，入校不允许 |
| 市北校区摆渡大巴         |  免费   |                                |

### 校外交通

| 交通工具 | 费用                   | 备注                                                                 |
|------|----------------------|--------------------------------------------------------------------|
| 地铁   | 依照“递远递减”的原则，采用里程分段计价 | [青岛地铁票务规则](https://www.qd-metro.com/news/view.php?id=1387#pagetop) |
| 公交   |                      | **未查询到官方文件**                                                       |
| 网约车  |                      | 从黄岛校区南门和薛家岛地铁站之间往返10元左右                                            |
