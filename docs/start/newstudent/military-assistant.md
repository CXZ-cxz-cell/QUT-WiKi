# 军训及班助

> 新生军训通常持续 14 天左右，具体安排以学院和辅导员通知为准。

## 物品准备

- 防晒霜：建议多备，青岛夏季日照较强。
- 软鞋垫：军训鞋垫偏硬，提前准备能减少脚部不适。
- 大水杯：建议 1.5L 起步，方便训练间隙补水。
- 腰带：军训服一般包含束腰、帽子、外套、T 恤、裤子和鞋子，腰带通常需要自备。
- 藿香正气水：高温训练时可备用，如身体不适应及时向教官、班助或辅导员说明。
- 除湿袋：青岛湿度较高，宿舍衣柜和床铺周边可按需放置。

![军训物品参考](https://pic1.imgdb.cn/i/033zzv8unwsg1LKxH1aYNG.webp)

## 注意事项

- 训练期间注意防晒和补水，不要硬撑身体不适。
- 新生阶段遇到军训、请假、班级事务等问题，可以优先咨询班助、辅导员或班委。
