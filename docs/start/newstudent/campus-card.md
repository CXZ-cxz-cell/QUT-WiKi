# 校园一卡通

> 校园一卡通主要用于校内身份识别、门禁、图书馆、消费等场景,下文简称**校园卡**。

## 新生领取

- 新生到校后，向班助出示身份证件，可以领取到校园卡，校园卡上方印有姓名、学号、学院、专业等信息。

## 校园卡功能

- 校园卡可用于校内考试身份识别，图书馆门禁，食堂消费，水卡消费，电费充值
- 校园卡为加密卡，无法录入手机NFC，也没有交通卡功能

## 校园卡充值

详见[水电费充值](/start/campus-life/systems/utility-bill)页面中的**一卡通充值**

## 校园卡挂失及补办

- **挂失**: 支付宝进入**完美校园小程序**，点击**校园卡**，进入后选择**卡挂失**
- **补办**: 携带**身份证**前往**食堂**，使用校园卡自助机进行补办
