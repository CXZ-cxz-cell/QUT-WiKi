# 校园一卡通

> 校园一卡通主要用于校内身份识别、门禁、图书馆、消费等场景。校园电话卡和校园网不是同一个概念，是否办理电话卡应根据自身需求判断。

## 校园卡

- 校园卡相关业务可关注学校后续通知，报到后按学院安排办理或激活。
- 图书馆等部分场景支持刷脸或校园卡进入，首次使用人脸识别可能需要先通过校园卡完成信息录入。
- 校园卡遗失后应尽快挂失，并按学校指定渠道补办。

## 校园电话卡

- 新生入学季可能会遇到校园电话卡推销，请不要轻信“不办理电话卡就无法使用校园网或校内系统”等说法。
- 不办理校园电话卡不会影响正常使用校内系统。
- 校园电话卡标称的大流量，往往包含限定校园或学校周边区域使用的流量，办理前应看清套餐说明。
- 如果只是需要校园网，建议先阅读[校园网](/start/newstudent/campus-network)页面，根据实际用网需求选择套餐。
