# 入学准备清单

> 本页整理自新生入学指南，适合作为报到前的检查清单。具体材料要求以录取通知书、学院和辅导员通知为准。

## 证件材料

- 录取通知书
- 身份证：建议复印两到三份备用。
- 一寸、二寸蓝底照片：各准备一版。
- 团员档案
- 学籍档案
- 户口本复印件：仅迁户口时使用。

## 宿舍用品

学校超市能购买到的常规生活用品可到校后补齐，以下物品建议提前准备：

- 插排：可选择带 USB 口的款式。
- 台灯：建议选择充电款。
- 耳塞、眼罩：宿舍作息不完全一致时会比较实用。
- 床上用品：建议自备。
- 除湿袋：青岛湿度较高，可用于衣柜、床铺周边。

如果发现宿舍门窗、床铺、电路等设施有问题，应及时向楼管报备。

## 快递地址

黄岛校区常用快递地址：

```text
山东省青岛市黄岛区嘉陵江路 777 号青岛理工大学
```

建议提前两天寄出，尽量避开开学高峰。

## 常用 App

- 学习通：常用于签到、作业、考试等。
- 知到：部分课程可能会使用。
